# Contributing to Aether

We welcome contributions to **Aether — Spatial DeFi Workspace & Execution Layer**!

## Development Setup

```bash
# Clone the repository
git clone https://github.com/Huc06/Aether.git
cd Aether

# Install dependencies
npm install

# Start development server
npm run dev
```

## Production Build & Verification

Before submitting PRs, ensure tests and builds pass cleanly:

```bash
npm run build
```
